# Radian/degree conversions

Convert radians to degrees and vice versa

## Usage

``` r
radians(deg)

degrees(rad)
```

## Arguments

- deg:

  degrees

- rad:

  radians

## Value

numeric

## Functions

- `radians()`: Degrees to radians

- `degrees()`: Radians to degrees

## Examples

``` r
radians(180)
#> [1] 3.141593
degrees(pi)
#> [1] 180
```
