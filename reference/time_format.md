# Format time for printing

Format time for printing

## Usage

``` r
time_format(secs)
```

## Arguments

- secs:

  numeric. seconds

## Value

character

## Details

Code from
[`timetaken`](https://rdrr.io/pkg/data.table/man/timetaken.html)

## Examples

``` r
time_format(90)
#> [1] "00:01:30"
```
